# 영상 의뢰 — 뽑뽑이 홍보용 쇼츠(세로 숏폼) 편집

- 프로젝트: pick (한국명 **뽑뽑이**, 영문명 TakeDoll) — Android 인형뽑기 캐주얼 게임, 2026-11 한국 출시
- 의뢰자: PD / 날짜: 2026-11-01
- 작업자: Codex (영상 편집 담당)

## 1. 목적
- 유료 마케팅 없이 YouTube Shorts · TikTok · Instagram Reels 에 올릴 **무료 홍보용 짧은 영상**을 만든다.
- 목표: 스크롤을 멈추게 하는 첫 2초 → "나도 해 보고 싶다" → 스토어 검색 "뽑뽑이" 유도.

## 2. 녹화 — Unity 에디터 + Unity Recorder 로 직접 녹화
휴대폰 화면 녹화 대신 **Unity 에디터 Play 모드 화면을 Unity Recorder 로 녹화**한다. (상태바·알림 없음, 1080x1920 고정, 게임 소리 포함)

### 2-1. 녹화 환경 준비 (Codex)
- 프로젝트: `D:\pick` (Unity **6000.3.20f1**, URP). PD 가 같은 프로젝트를 에디터로 열어 둔 상태일 수 있으니, 패키지·에셋 변경 전에 열려 있는지 확인하고 열려 있으면 PD 에게 알린다.
- **Unity Recorder 패키지 추가**: `com.unity.recorder` (Unity 6.3 과 호환되는 최신 안정 버전) — Package Manager 또는 `Packages/manifest.json`. 에디터 전용 패키지라 빌드(앱)에는 들어가지 않는다.
- **녹화 프리셋**: Movie Recorder, 출력 `D:\pick\_shorts\raw\bbop_rec_<날짜시간>.mp4`, MP4(H.264), **1080x1920**, 30fps(Constant), **Audio 포함**, Game View 소스.
- **원클릭 메뉴(에디터 스크립트)**: `Assets/Editor/Shorts/` 아래에 만든다.
  - `Tools/Shorts/녹화 시작` — Game View 해상도를 1080x1920 으로 맞추고 → Play 모드 진입 → 녹화 시작
  - `Tools/Shorts/녹화 종료` — 녹화 저장 후 Play 모드 종료 (Play 모드를 끝내도 저장되게)
  - 메뉴 스크립트는 `#if UNITY_EDITOR` / Editor 폴더라 빌드에 포함되지 않아야 한다.
- 준비가 끝나면 짧은 테스트 녹화(10초)로 해상도·소리·저장 위치를 확인하고 결과를 보고서에 적는다.

### 2-2. 플레이 조작 (녹화하는 사람용 안내 — edit_notes.md 에도 적을 것)
- 크레인 이동: **W/A/S/D** (또는 마우스로 화면 조이스틱 드래그), 집기: **Space** (또는 집기 버튼 클릭)
- 원하는 장면 만들기용 기존 디버그 메뉴:
  - `FunRabbit/Debug/코인 100,000으로 설정` — 코인 걱정 없이 계속 녹화
  - 스테이지 이동 메뉴(DebugStageMenu, "스테이지 1~36") — 변형 인형(파랑·빨강), 다양한 동물이 나오는 스테이지로 이동
  - 언어 메뉴(DebugLanguageMenu) — **한국어(KOR)** 로 고정해서 녹화
- 녹화는 **Codex 가 에디터를 조작할 수 있으면 직접**, 불가능하면 **PD 가 위 메뉴로 플레이하며 녹화**한다. 어느 쪽이었는지 보고서에 적는다.

### 2-3. 녹화 소재 기준
- 3장의 볼거리(여러 개 잡기, 아깝게 놓치기, 황금 인형, 콤보, 랜덤박스, 보스 처치·클리어, 도감)가 들어가도록 여러 판 녹화.
- 소재가 부족하면 **임의로 만들지 말고** 부족한 장면 목록을 보고서에 적는다.
- 디버그용 화면(디버그 메뉴 창, 콘솔, 테스트 버튼 등)이 Game View 에 찍히지 않게 한다.

## 3. 게임 이해 (영상에 보여 줄 수 있는 실제 요소만)
- 크레인(집게)을 조이스틱으로 움직여 기계 안의 뜨개 인형을 집는다. 1판 15초 제한.
- 인형을 바구니에 넣으면 그 동물이 **아군**이 되어 화면 위쪽에서 **보스와 자동 전투**한다.
- 볼거리:
  - 한 번에 인형 2~3개 잡기 / 아깝게 놓치기
  - **황금 인형**(금속처럼 반짝임, 잡으면 아군 3마리 합류)
  - **콤보**("2 콤보", "3 콤보" 문구가 튀어나오며 효과음) — 연속으로 잡으면 아군 추가
  - 랜덤박스 개봉, 코인이 날아가 쌓이는 연출(코인 카운트 효과음)
  - 보스 처치 → 스테이지 클리어 패널
  - 도감(컬렉션): 획득한 인형들이 들판을 돌아다니고, 탭하면 울음소리
- 동물: 소·돼지·곰·문어·코끼리·개구리·원숭이·말·코알라·사자·판다·오리 등, 후반엔 파랑/빨강 변형.
- ⚠️ 게임에 없는 기능·보상·과장 문구 금지(예: "현금 지급", "100% 당첨", 실제 경품). 스토어 광고 정책·표시광고법 위반 소지.

## 4. 산출물
출력 폴더: `D:\pick\_shorts\out\`

| 파일명 | 길이 | 내용 |
|---|---|---|
| `bbop_shorts_A_15s.mp4` | 12~15초 | 하이라이트 압축형: 최고 장면(황금 인형 또는 3개 잡기)으로 시작 → 콤보 → 보스 처치 → 엔딩 카드 |
| `bbop_shorts_B_30s.mp4` | 25~30초 | 스토리형: "이게 돼?" 아깝게 놓침 → 재도전 성공 → 아군이 보스를 때림 → 클리어 → 도감 → 엔딩 카드 |
| `bbop_shorts_C_20s.mp4` | 18~20초 | 수집형: 다양한 인형 연속 획득 몽타주 → 도감에 하나씩 채워짐 → "몇 마리 모았어?" → 엔딩 카드 |
| `bbop_thumb_A.png` / `_B` / `_C` | - | 각 영상의 커버 이미지(1080x1920, 가장 눈에 띄는 프레임 + 큰 제목) |
| `edit_notes.md` | - | 사용한 원본 파일·구간(타임코드), 자막 전문, 처리 내역, 부족했던 소재 |

공통 규격:
- 1080x1920 (9:16), 30fps(원본이 60이면 60 유지 가능), H.264 High, yuv420p, AAC 48kHz 스테레오, 비트레이트 8~12Mbps, mp4(faststart)
- 파일당 50MB 이하
- 녹화를 1080x1920 으로 하므로 원칙적으로 크롭 불필요. 다른 비율로 녹화된 소재가 섞이면 **잘라내기(crop)**로 맞추고, 게임 UI(조이스틱·버튼)가 잘리지 않게 한다. 레터박스(검은 띠) 금지.

## 5. 편집 지침
1. **첫 2초가 승부**: 영상 맨 앞에 가장 강한 장면(황금 인형 집기, 3개 동시 잡기, 큰 콤보)을 둔다. 로고·타이틀 화면으로 시작하지 않는다.
2. **템포**: 크레인 이동처럼 지루한 구간은 1.5~2배속 또는 컷. 집게가 인형을 들어 올리는 순간~바구니에 떨어지는 순간은 정속 또는 0.7배 슬로.
3. **자막**(한국어): 화면당 1줄, 10자 안팎, 굵은 고딕(Windows `C:\Windows\Fonts\malgunbd.ttf` 등), 흰 글자 + 검은 외곽선 4~6px. 등장은 짧게 튀어 오르는 정도만.
   - 문구 후보(상황에 맞는 것만 사용, 수정 가능):
     - "이게 한 번에 잡힌다고?" / "3마리 동시에?!" / "황금 인형 떴다" / "놓쳤다… 한 번 더!"
     - "잡은 인형이 같이 싸워줌" / "보스 한 방에 컷" / "콤보 터졌다"
     - "도감 다 채울 수 있을까?" / "몇 마리 모았어?"
4. **Shorts 안전 영역**: 자막·핵심 장면을 화면 **아래 20%, 오른쪽 15%, 위 10%** 밖에 두지 않는다(플랫폼 UI 버튼에 가려짐).
5. **소리**: 게임 원래 소리(효과음·울음소리)를 살린다. 음량 정규화 약 -14 LUFS, 피크 -1 dBTP. **배경음악은 넣지 않는다**(저작권). 넣고 싶으면 넣지 말고 보고서에 제안만.
6. **엔딩 카드**(마지막 1.5~2초): 게임 화면 위에 반투명 어둡게 + 중앙 "뽑뽑이" 큰 글자 + 아래 "Google Play 에서 '뽑뽑이' 검색". 앱 아이콘이 필요하면 `D:\pick\Assets` 안의 앱 아이콘 이미지를 찾아 쓰되 원본은 수정하지 않는다.
7. 개인정보가 찍힌 구간(로그인 화면의 계정 이메일 등)은 쓰지 않는다.

- 작업용 중간 파일은 `D:\pick\_shorts\work\` 에 두고, 최종본만 `out\` 에 둔다.

## 8. 하지 말 것
- 수정 허용 범위는 **`D:\pick\_shorts\`, `Packages/manifest.json`(+ packages-lock.json)의 Recorder 추가, `Assets/Editor/Shorts/` 신규 파일, Recorder 설정 에셋**뿐이다. 그 밖의 `Assets\`(게임 코드·씬·프리팹·데이터), ProjectSettings 수정 금지. git 커밋 금지.
- 녹화 때문에 바뀐 게임 저장값(코인 100,000, 스테이지 이동 등)은 에디터 PlayerPrefs 라 앱에는 영향 없음 — 녹화 후 원래대로 되돌릴 필요는 없지만, 바꾼 내역은 보고서에 적는다.
- 원본 녹화 파일(`raw\`) 수정·삭제 금지
- 저작권 있는 음악·이미지·폰트(상업 이용 불가 폰트) 사용 금지
- 게임 화면을 가짜로 합성하거나 실제와 다른 결과처럼 보이게 편집 금지
